## LOD GENERATION

Step 1. Process a Model by selecting it. I recommend downloading [AssetDeliveryProxy](https://github.com/TylerAtStarboard/RobloxAssetDeliveryProxy/tree/main?tab=readme-ov-file) so that processing assets not made by you is possible.<br/>
Step 2. Add an LOD "level" by clicking "Add Mesh Element" or "Add Billboard Element" and choose an LOD generation method (Vertex Clustering, QMS, Custom).<br/>
Step 3. Customize the settings, experiment a little, then click Generate Mesh.<br/>
Step 4. After you added the desired LOD levels, you can name your template and click Generate Template (you need to click Insert LOD Folder first if you haven't done that).

## SETTINGS EXPLANATION

#### GENERAL

There are a form of setting called Timeout settings, they just control CPU load, the higher the value the more aggressive the load is

Insert LOD Folder - inserts the LOD module<br/>
Reset Settings - defaults all settings<br/>
Use Box Parts - processes all parts as blocks (i forgot why i added this setting its pretty useless)<br/>
Ignore Unprocessable Parts - when off parts that cannot be processed (assetdelivery error, etc..) will be rendered as box parts, when on they are treated as non-existent<br/>
Texture Sampling Radius - the radius of the texture sampling (on the UV) -><br/>
Texture Sampling Iterations - the amount of pixels to average from       -> I recommend leaving these 2 alone, they're pretty useless<br/>
Use Averaged Material Colors - tints coloring with the material's average color<br/>
Pre 2022 Materials - this copies the workspace setting since it's not readable<br/>
Mesh Blockiness - this controls how close the generated normals will be to the perfect "blocky" triangle normal (this fixes normal vector issues)<br/>
Mesh Generation Timeout - timeout setting for converting the table of triangles to an editablemesh<br/>
**X - rendering coefficient this is an extremely important setting, it controls selected LOD quality, the higher the value the lower the quality**<br/>
Unrender Cell Size - the cell size that corresponds to the cell size where the model should be unloaded completely (visually), this basically corresponds to model size but can be smaller if you need it to unload earlier<br/>
Start Preview, Stop Preview - self explanatory, starts and stops the LOD preview<br/>
Template Name - self explanatory, the name of the LOD template<br/>
Pixel Line Precision - how many decimal places of precision the pixel lines generated by vertex clustering have<br/>
Generate Template - self explanatory, publishes the template to roblox and places it in the LOD folder

#### VERTEX CLUSTERING SETTINGS

Vertex Clustering is a mesh decimation algorithm that contracts vertices into little cells and deletes their shared triangles<br/>
- Pros -> fast, good for sparse geometry<br/>
- Cons -> small details are completely ruined

Cell Color Averaging Bias - controls how much a cell's main vertex's color is interpolated towards the average cell color (1 = cell color is equal to the average of all vertices within the cell, 0 = cell color is equal to the main vertex's color)<br/>
Vertex Clustering Timeout - timeout setting for the algorithm<br/>
Generate Dynamic Normals - dynamic normals are rectangular lines that fix the issue of vertex clustering where it turns triangles into 1 pixel wide lines<br/>
Maximum Pixel Lines - sets the maximum amount of pixel lines generated by the algorithm (too many pixel lines can't fit in a modulescript)

#### QMS SETTINGS

QMS (Quadric Mesh Simplification) that contracts edges and close vertices while preserving mesh volume<br/>
- Pros -> perfectly preserves mesh volume<br/>
- Cons -> Extremely slow (basically unusable at >100k tris)<br/>
The algorithm applies penalties on undesirable contractions

QMS Timeout - timeout setting for the algorithm<br/>
Merging Threshold - this algorithm merges "same" vertices because this algorithm performs the best with connected geometry, these thresholds control when 2 vertices are considered the same (high threshold - more merging)<br/>
Angle of an Edge - if the angle between 2 edges is smaller than this value then they are considered a pixel line, in which case the contraction counts as an inversion (which is penalized)<br/>
Minimum Angle of Inversion - if the angle between the old angle and the new angle of a triangle pre and post contraction is bigger than this value, then it counts as an inversion<br/>
Inversion Penalty - how much inversion are penalized<br/>
Boundary Penalty - the algorithm tends to eat triangles that are boundaries, this setting prevents that by penalizing boundary contractions<br/>
Maximum Error - contractions that have a higher error (+ penalty) than this value are discarded<br/>
Alpha, Color Penalty - how much color differences are penalized<br/>
Determinant Tolerance - if the absolute value of a matrix's determinant is smaller than this value, it is considered to be non-invertable<br/>
Balancing Settings - how much the color of the contracted vertex affects the color of the other vertex

#### BILLBOARD SETTINGS

This plugin is capable of generating billboards, that is, decals that pre-render the appearance of the model in order to improve performance (especially used for cylindrical objects like trees)<br/>
This setting however, is pretty experimental, due to how gpu instancing and culling works, this may not help performance that much

Billboard Generation Timeout - timeout setting for billboard generation (rendering on the cpu is a bit slow lol)<br/>
Ambient - the ambient color used for ambient occlusion<br/>
Ambient Occlusion Samples - the amount of samples taken for calculating AO<br/>
Ambient Occlusion Distance - the maximum distance of each AO ray

#### SETTINGS FOR LOD LEVELS

Cell Size - controls Vertex Clustering's cell size + determines the "quality" (not the actual quality, just how the lod selection at runtime sees it) of the level - higher cell size means the level only pops into view far

#### SETTINGS FOR MESH ELEMENTS

QMS specific settings:<br/>
  - Target Tri Count - QMS decimates the mesh until a certain tri count is met (kind of, there are other exit conditions), this setting controls that maximum tri count<br/>
  - Pairing Threshold - QMS contracts non-connected vertices by selecting pairing those that are close enough - the higher this is the better the algorithm deals with disconnected geometry, but setting this too high slows the algorithm down by a ton so be careful<br/>

Custom LOD Models - you can add a custom LOD model as a level<br/>
LOD Texture, LOD SurfaceAppearance - you can set the texture/surfaceappearance of the generated mesh if you would like to (this is especially useful when creating LODs of a single mesh)<br/>
Generate Transparent Mesh - generates a separate transparent mesh in order to help fix clipping when using per-vertex transparencies

#### SETTINGS FOR BILLBOARD ELEMENTS

Resolution - self explanatory, the resolution of one decal<br/>
Sides - how many sides of the model are rendered<br/>
Y Angle - the vertical angle where the top down view of the model starts becoming visible

## RUNTIME USE

The datatype hierarchy within the module is: ModelRegion -> ModelGroup -> LODModel<br/>
ModelRegion is a set of LODs that loads in at the same time to optimize the amount of distance checks<br/>
ModelGroup is a child of ModelRegion and has a set template (the template generated from the LOD GENERATION segment)<br/>
LODModel is a specific instance (a model) which has been added to the LOD pipeline

Here's an example of an automated LODification algorithm to help you understand the basic architecture

	local REGION_SIZE = 100
	
	local LOD = game:GetService("ReplicatedStorage").LOD
	local Templates = LOD.Templates
	local LODService = require(LOD.LODService)
	
	local regionCount = 0
	local modelCount = 0
	local groupCount = 0
	
	
	-- you can use GetDescendants here aswell
	for _, v : Instance in workspace:GetChildren() do
		if not v:IsA("Model") then
			continue
		end
		
		local templateModule = Templates:FindFirstChild(v.Name)
	
		if not templateModule then
			continue
		end
	
		modelCount += 1
	
		local template = require(templateModule)
		local pivot = v:GetPivot().Position
	
		local foundRegion = false
	
		for _, region in _G.regions do
			if (region.pivot - pivot).Magnitude < REGION_SIZE then
				foundRegion = true
	
				local foundGroup = false
	
				for _, group in region.groups do
					if group.template == template then
						foundGroup = true
						group:LODifyModel(v)
						break
					end
				end
	
				if not foundGroup then
					groupCount += 1
					region:CreateGroup(template):LODifyModel(v)
				end
	
				break
			end
		end
	
		if not foundRegion then
			regionCount += 1
			groupCount += 1
			LODService:CreateRegion(pivot):CreateGroup(template):LODifyModel(v)
		end
	end
	
	LODService:Run()
	print(string.format("LODService started with %i regions, %i groups and %i models", regionCount, groupCount, modelCount))
